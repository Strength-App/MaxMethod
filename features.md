# Features

A running log of features in MaxMethod, in plain language. When you add a new
feature, add an entry here describing **what it does**, **who it's for**, and
**how it works at a high level** — written so a non-technical reader can follow.

Newest entries go at the top.

---

## Template (copy this for a new feature)

### <Feature name>

- **Date added:** YYYY-MM-DD
- **What it does:** One or two plain sentences a non-programmer would understand.
- **Who it's for:** The kind of user this helps and when they'd use it.
- **How it works (high level):** The steps from the user's action to the result,
  including which parts of the app are involved (frontend screen, backend route,
  database).
